# S88x Creative Agency Landing Page

A full-screen hero landing page built with React, TypeScript, Vite, and Tailwind CSS.

## Features

### 🎬 Background Video with Mouse Scrubbing
- Full-screen fixed video element with `object-fit: cover`
- Interactive mouse-controlled scrubbing using horizontal movement
- Smooth seeking with clamped time values

### 🎨 Custom Fonts
- **Heading Font**: HelveticaNowDisplay-Medium
- **Body Font**: HelveticaNowDisplayW01-Rg
- CSS variables for easy customization

### 📱 Responsive Navbar
- Logo with "Mainframe®" text and decorative asterisk
- Desktop navigation links with hover effects
- Mobile hamburger menu with smooth animations
- Full-screen mobile overlay

### 🎯 Hero Section
- Full-screen height with responsive positioning
- Blurred intro label with custom text
- Typewriter animation with character reveal
- 4 white pill buttons + 1 outline email button
- Copy-to-clipboard functionality

### ✨ Interactive Elements
- Custom useTypewriter hook
- Fade-in + slide-up button animation
- Video scrubbing with mouse movement
- Smooth transitions on all interactive elements

## Installation & Development

```bash
npm install
npm run dev
npm run build
```

Dev server: `http://localhost:5173/`

## Dependencies

- React 18+
- TypeScript
- Vite
- Tailwind CSS
- PostCSS
- Autoprefixer
