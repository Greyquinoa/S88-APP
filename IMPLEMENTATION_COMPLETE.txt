USAGE:
─────────────────────────────────────────────────────────────────────────────

Extract from CFG:
  const extractor = new ModuleParameterExtractor();
  const params = extractor.extractAllParameters(cfgContent);

Store in Database:
  ModuleParameterDb.insertModuleParameters(hwSignalId, params);

Query Parameters:
  const all = ModuleParameterDb.getParametersBySignal(hwSignalId);
  const grouped = ModuleParameterDb.getParametersGrouped(hwSignalId);
  const ch0 = ModuleParameterDb.getChannelParameters(hwSignalId, 0);
  const results = ModuleParameterDb.getParametersByName('CHANNEL_ACTIVATED');
